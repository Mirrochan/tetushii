## Генератори (generators/)
Конвеєр: HTML → скриншот і вимір → компактний JSON → JS для `use_figma`.
- `p4.py`: усі екрани застосунку. `s3.py`: сайт, мобільна версія, панель. `s4.py`: Тутешні-сторінки (головні, Г, МГ). Рендер через Playwright Chromium.
- `extract5.py` перетворює DOM у JSON. `fig6.py` генерує батчі для Figma. `mockfig.js` дає сухий прогін батчу в node.
- HTML генерується в старій «зеленій» темі: кольори мапляться на токени й прив'язуються до змінних, тож у Figma вони сині.
